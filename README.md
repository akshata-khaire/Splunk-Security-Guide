# *Splunk-Security-Guide - A Guide to Splunk, SPL Queries, Log Analysis, & Defensive Security.*
A structured reference covering basic SPL commands and security focused queries for log analysis and threat detection.
## About 
This repository is created as a learning and reference resource for understanding how Splunk and SPL can be used in defensive security.

The repository focuses on building a foundation in SPL and applying that knowledge to common security monitoring and investigation scenarios.
- **20 SPL Search Examples For Defensive Security:**
  Contains 20 SPL queries covering common security monitoring, threat detection, and log analysis scenarios.
- **SPL Basic Commands:**
  Contains commonly used SPL commands and functions with simple descriptions and examples.

## Usage
This repository provides organized SPL references for learning and practice. Explore the available files to understand the commands and queries, their purpose, and how they can be used for security monitoring and log analysis.

## Disclaimer
This repository is intended for educational and defensive security purposes. Use these queries responsibly and only on systems and data you are authorized to monitor or analyze.
