# *A Beginner-Friendly Reference for Commonly Used SPL Commands*
**1. Search a Specific Index**
```
index=security
```
*Searches for events stored in the specified security index.*

**2. Search for a Keyword**
```
index=security failed
```
*Searches the security index for events containing the keyword `failed`.*

**3. Combine Conditions with AND**
```
index=security user=admin action=failed
```
*Searches for events matching all specified conditions.*


**4. Search Multiple Conditions with OR**
```
index=security (action=failed OR action=blocked)
```
*Searches for events matching either condition.*

**5. Exclude Results with NOT**
```
index=security NOT action=success
```
*Excludes events where the action is `success`.*

**6. Search Using a Relative Start Time**
```
index=security earliest=-24h
```
*Searches for events from the previous 24 hours.*

**7. Define a Search Time Range**
```
index=security earliest=-24h latest=now
```
*Limits the search range to the last 24 hours up to the current time.*

**8. Filter by Sourcetype**
```
index=security sourcetype=WinEventLog
```
*Searches events belonging to the specified sourcetype.*

**9. Filter by Source**
```
index=security source="WinEventLog:Security"
```
*Searches events originating from the specified source.*

**10. Filter by Host**
```
index=security host="DC01"
```
*Restricts the search to events generated by a specific host.*

**11. Select Specific Fields**
```
index=security | fields _time, user, src_ip, dest_ip
```
*Keeps only the specified fields in the search results.*

**12. Format Results as a Table**
```
index=security | table _time, user, src_ip, action
```
*Displays selected fields in a clean table.*

**13. Rename a Field**
```
index=security | rename src_ip AS source_ip
```
*Changes the name of `src_ip` to `source_ip`.*

**14. Remove Duplicate Results**
```
index=security | dedup user
```
*Removes duplicate results based on the `user` field.*

**15. Sort Search Results**
```
index=security | sort -_time
```
*Sorts the results by time in descending order*

**16. Return the First N Results**
```
index=security | head 10
```
*Returns the first 10 results.*

**17. Return the Last N Results**
```
index=security | tail 10
```
*Returns the last 10 results.*

**18. Calculate Event Statistics**
```
index=security | stats count by user
```
*Counts the total events and groups the results by user.*

**19. Count Total Events**
```
index=security | stats count
```
*Calculates the total number of matching events.*

**20. Count Unique Values**
```
index=security | stats dc(user) AS unique_users
```
*Counts the number of distinct users.*

**21. List Unique Values**
```
index=security | stats values(src_ip) AS source_ips
```
*Creates a list of unique source IP addresses.*

**22. Calculate an Average**
```
index=security | stats avg(duration) AS average_duration
```
*Calculates the average value of the `duration` field.*

**23. Calculate a Total**
```
index=security | stats sum(bytes) AS total_bytes
```
*Calculates the total value of the `bytes` field.*

**24. Find the Minimum Value**
```
index=security | stats min(duration) AS minimum_duration
```
*Finds the smallest value in the `duration` field.*

**25. Find the Maximum Value**
```
index=security | stats max(duration) AS maximum_duration
```
*Finds the largest value in the `duration` field.*

**26. Filter Results with `where`**
```
index=security | stats count by user | where count > 10
```
*Filters the results based on a specified condition.*

**27. Create a Calculated Field with `eval`**
```
index=security | eval total_mb=bytes/(1024*1024)
```
*Creates a new field by performing a calculation*

**28. Apply a Conditional Value with `if`**
```
index=security | eval status=if(action="blocked","Suspicious","Allowed)"
```
*Creates a field whose value depends on a specified condition.*

**29. Find Null Fields**
```
index=security | where isnull(src_ip)
```
*Finds events where the `src_ip` field has no value.*

**30. Find Non-Null Fields**
```
index=security | where isnotnull(src_ip)
```
*Finds events where the `src_ip` field contains a value.*
